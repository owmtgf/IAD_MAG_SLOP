ПРАКТИКА 1 — РАСПРЕДЕЛЕНИЕ ЗАДАЧ БЕЗ LLM
=======================================

Начните с practice_01_task.pdf.
Нужен Python 3.10 или новее. Установка пакетов, API-ключи и интернет
для запуска не требуются. На Windows вместо python может понадобиться py.

1. Откройте терминал В ПАПКЕ students (или в корне студенческого ZIP).
2. Проверьте готовые компоненты:

   python -m unittest discover -s tests -v
   python run.py --case demo_17_vs_5 --methods independent exact

Пять тестов TODO будут иметь SKIP: это НЕ успешная сдача.
Шесть тестов готовых компонентов должны пройти.

3. Реализуйте greedy и contract_net в starter.py.
4. Проверьте весь набор:

   python -m unittest discover -s tests -v
   python run.py

Теперь должны пройти все 11 тестов, без SKIP.

5. Проверьте другой порядок задач:

   python run.py --case demo_17_vs_5 --methods contract_net --order 1,0,2

Выходы пишутся в results/ и перезаписываются следующим запуском.
Для сохранения отдельного эксперимента используйте --out results_order_102.
Чтобы сохранить базовый набор до экспериментов, используйте --out results_all.

ФАЙЛЫ
  core.py             Готовые типы, валидация, точный перебор.
  starter.py          Два TODO: жадное назначение и Contract Net.
  run.py              Запуск, метрики, CSV и трассы JSON.
  data/cases.json     Ровно 30 фиксированных матриц, n от 3 до 7.
  tests/              Автотесты; SKIP = TODO ещё не выполнен.
  report_template.md  Шаблон отчёта.
  prompts.md          Промпты и инструменты или запись об отсутствии ИИ.
  papers_next_class.pdf  Четыре статьи к следующему занятию.

ИНТЕРПРЕТАЦИЯ
  assignment[i] — задача агента i, индексы с нуля.
  cost и gap пусты, если назначение недопустимо.
  proposal_cost — сумма индивидуальных предложений, не итоговая метрика.
  messages пусто у централизованных методов: обмен не моделировался.
  Для Contract Net один адресат = одно сообщение, включая INFORM.
  elapsed_ms — время локального Python, не скорость реальной MAS.

СДАТЬ — БЕЗ ЗАЩИТЫ
  Промпты: prompts.md. Если не использовали ИИ, явно напишите об этом.
  Код: starter.py и команды воспроизведения.
  Результаты: results.csv, summary.csv, одну трассу и все шесть порядков.
  Отчёт: 1–2 страницы с результатами, анализом и выводами.
  Готовый шаблон — report_template.md; таблицы можно приложить отдельно.
  Можно работать в паре. Укажите участников и их вклад.
  Отдельной, в том числе краткой, защиты лабораторной нет.
