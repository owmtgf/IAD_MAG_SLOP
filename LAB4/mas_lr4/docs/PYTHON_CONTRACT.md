Допустимый Python для D/T/H/C задач

Контракт применяется одинаково ко всем ролям нового запуска. Многомодульные проекты M01-M03 и реестр M04 используют отдельный исполнитель с классами и стандартной библиотекой.

Исполнитель поддерживает ограниченное подмножество Python. Ниже — явные правила и точные списки доступных встроенных имён и методов; окончательная проверка синтаксиса задаётся в worker.py.

1. Модуль содержит только определения функций, включая solve(data). Вспомогательные функции разрешены. Нельзя создавать глобальные константы или выполнять выражения на уровне модуля. Входные данные нельзя изменять.
2. Разрешены обычные литералы (None, bool, числа и строки), присваивание и присваивание с операцией, return, if/else, for, while, break, continue, pass, raise, выражение вида a if condition else b, lambda, индексы и срезы, списки, кортежи, словари, множества, comprehensions и генераторные выражения.
3. Арифметика: +, -, *, /, //, %, **. Битовые операции: только | и &. Разрешены логические not/and/or и сравнения ==, !=, <, <=, >, >=, in, not in, is, is not. Унарные + и - разрешены.
4. Нельзя использовать del, <<, >>, ^, ~, :=, import, классы, try/except/finally, with, assert, async/await, yield, global/nonlocal, декораторы, аннотации, f-строки и конструкции с AST-узлом Starred (например, вызов f(*items) или a, *tail = items). Нельзя обращаться к файлам, сети или средствам introspection. Имена с начальным подчёркиванием запрещены, кроме одиночного _.
5. Для удаления элемента словаря используйте pop(key, default), а не del. Для степени двойки используйте 2 ** n, а не 1 << n.
6. Встроенные имена: abs, all, any, bool, dict, enumerate, float, int, isinstance, len, list, max, min, next, range, reversed, round, set, sorted, str, sum, tuple, zip, ValueError, TypeError, KeyError, IndexError. Другие встроенные имена недоступны. Определённые вами вспомогательные функции вызывать можно.
7. Допустимые имена методов: append, extend, insert, pop, remove, sort, reverse, copy, get, items, keys, values, setdefault, update, count, index, join, split, strip, lstrip, rstrip, lower, upper, startswith, endswith, replace, isdigit, add, discard, difference, intersection, union, issubset. Метод должен существовать у соответствующего объекта. Другие атрибуты и методы запрещены.
8. Вызов функции допускается по имени или через разрешённый метод. Косвенный вызов вроде functions[0](x) запрещён.
9. Итог solve(data) — конечное JSON-значение: null/None, bool, int, конечный float, str, список либо словарь со строковыми ключами. Кортежи и множества допустимы для промежуточных вычислений, но не в итоговом значении. Порядок списков и точные типы проверяются. Одинаковый вход должен давать одинаковый результат. Если условие явно требует исключение вместо результата, выбросите исключение указанного типа: исполнитель проверяет точное имя типа, но не текст сообщения. Запрет изменения входа действует и при исключении.
10. Ограничения исполнителя: код не более 40 000 байт UTF-8; не более 200 000 выполненных строк программы на тест, включая два запуска для проверки детерминизма. Вложенность итогового JSON — не более 60 уровней.

Источник: maslab/worker.py; дополнительные проекты: advanced/worker.py и advanced/sandbox.py.
