Начните с **report/LAB4_report.md**: отчёт в Markdown с результатами,
парным сравнением и разбором трёх трасс. Локальные пути и адреса сервера
из отчёта убраны; технические параметры воспроизведения находятся ниже.
Рядом находится **report/LAB4_report.pdf** с тем же содержимым.
Исходный README.md комплекта преподавателя сохранён отдельно от этой инструкции.

## Что реализовано и проверено

- maslab/student_policies.py: fixed и coordinator для D/T/C.
- advanced/student_policies.py: обе политики для проектов и реестра.
- Fixed: programmer → reviewer → programmer → независимая проверка,
  лимиты этапов 10/6/12. Замечание ревьюера передаётся явно.
- Coordinator: до 10 решений, до 3 действий исполнителя за делегирование,
  валидация точных JSON-схем, роли, типов и длины instruction.
- Отдельные истории, общий бюджет всех ролей, проверка текущего артефакта.
- Свои offline-сценарии: tests/test_student_policies.py; проверки LAN и
  сохранения изоляции — test_lan_provider.py и test_sandbox_runtime.py.
- 63 offline-теста проходят; лог — analysis/final/offline_tests.log.

## Модель и среда

Одна Qwen3.5-4B для всех схем/ролей. Точный API ID:
`/home/maria/Projects/IAD_MAG_neuroslop/lab02_students/Qwen3.5-4B`.
Сервер vLLM, RTX 5070, BF16, max_model_len=65536, max_num_seqs=1,
thinking выключен, reasoning-parser=qwen3. BF16/GPU/аргументы запуска
сообщены пользователем; API подтвердил ID, размер окна и нулевые reasoning-токены.
Endpoint во время эксперимента: `http://192.168.3.42:8000/v1`, ключ не требовался.
Клиент — `/home/owmtgf/anaconda3/bin/python`, Python 3.11.5, Linux/WSL2,
glibc 2.35, libseccomp; точная строка ОС записана в manifest.

temperature=0, send_seed=false, seed=41729. Бюджет включает повторную передачу
историй, вход и выход всех ролей. Финальные настройки:

| Блок | Общие бюджеты | Выход на ответ | Время эпизода | Повторы |
|---|---|---:|---:|---:|
| T | 24000/48000 | 1800 | 300 с | 2 |
| C | 60000 | 4000 | 600 с | 2 |
| M | 60000 | 6000 | 900 с | 2 |

Общие лимиты — 48 вызовов модели и 80 инструментальных действий.
Тарифы не заданы; стоимость неизвестна. Токены сверх бюджета учтены, действие
ответа за бюджетом не применяется. Неизвестный usage не заменён нулём.

## Проверка без LLM

Команды выполняются из корня распакованной папки mas_lr4, Python 3.11+.
Сторонних Python-пакетов не нужно. Для sandbox требуется Linux/libseccomp.

```bash
python -m unittest discover -s tests -v
python -m maslab doctor
python -m advanced doctor
python scripts/paired_analysis.py
python scripts/final_analysis.py
```

Последняя команда проверяет все 696 идентичностей, хеши сохранённых артефактов,
суммы фактического usage из трасс и по ролям, наличие финальных событий и freeze.
Файлы анализа создаются вне замороженных каталогов. Новых запросов к LLM нет.

## Команды итогового сравнения

Приведённые команды вызывают модель. Для нового воспроизведения используйте
новые папки вывода; оригинальные результаты не перезаписывайте.
Сервер должен обслуживать точный API ID из конфигов.

```bash
export MAS_LLM_BASE_URL=http://192.168.3.42:8000/v1
python -m maslab run --split test --out runs/reproduction_core
python -m maslab run --config docs/extra_config.json --freeze extra_freeze.json --split extra --out runs/reproduction_C
python -m advanced run --freeze advanced_freeze.json --out runs/reproduction_M
```

Для нового эксперимента с изменением параметров сначала создайте отдельную копию,
проведите dev и новую freeze. Не заменяйте приложенные снимки. Пилотные freeze
не являются итоговыми.

Реальный итоговый запуск выполнялся scripts/run_final.py и продолжался через
`--resume`. Одна пользовательская пауза привела к interrupted у
T17_coordinator_b24000_r1: он сохранён как неуспех с неизвестным расходом,
не был повторён. Использовался тот же Python 3.11.5; попытка продолжить из
slop/Python 3.12.14 была отклонена до новых модельных эпизодов.
Подробности — runs/PAUSE.md и журналы final_*.

## Изменения исходного комплекта и ограничения

До итоговой freeze по решению пользователя сделаны и раскрыты изменения:

1. Разрешён HTTP к конкретному адресу LAN в общем адаптере.
2. Уточнён общий base.txt: точные формы finish/yield; проведены полные dev-пилоты
   до/после. Baseline-код и правила валидатора не менялись.
3. Для Anaconda Landlock учитывает реальные каталоги stdlib/platstdlib;
   doctor проверяет dataclasses после установки изоляции. Тесты подтверждают
   запреты сети, запуска процессов, внешнего чтения и записи. Кэши/окружение
   Anaconda не включены в архив.
4. Бюджеты T изменены с 6000/12000 на 24000/48000 по результатам dev;
   конкретные итоговые значения отдельно с преподавателем не согласованы.
   Технические C/M-пилоты
   использовались для обнаружения нехватки контекста и дефекта среды;
   алгоритмы не подгонялись по финальным C/M. Все пилоты сохранены.

Общий base.txt и исполнитель исходным заданием менять запрещалось. Отдельного
согласования этих исправлений и конкретных итоговых бюджетов с преподавателем
не было. Поэтому сравнение проведено по изменённому протоколу и не является
воспроизведением исходного задания. Причины — исчерпание начальных лимитов
при повторной передаче входа и систематические ошибки формата finish на dev.
После итоговой заморозки экспериментальный код, данные и инструкции не менялись.
Низкие результаты M сохранены без выбора лучших попыток и без повторов ошибок.

Итоговые ограничения: 2 транспортные ошибки T, 15 таймаутов C и 1 прерывание,
всего 18 эпизодов с неизвестным полным usage. Два повтора не дают независимой
выборки из 100 задач; M04 — один интеграционный реестр, а не 40 независимых задач.
Сравнение по открытым примерам не доказывает корректность на всех входах.
Программная обработка корпуса была доступна всем, поэтому M04 не является
чистым тестом окна контекста.

Использование ИИ: реализация политик, offline-проверки, анализ и отчёт
подготовлены с помощью ИИ; выводы основаны на приложенных реальных запусках.
