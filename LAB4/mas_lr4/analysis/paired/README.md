# Парное сравнение с single

Пара: одна задача, бюджет и повтор; seed проверен на совпадение. Ошибки API, прерывание и исчерпание бюджета считаются неуспехами.

| Блок | Бюджет | Команда | Оба успешны | Только команда | Только single | Оба неуспешны | Разница, п.п. |
|---|---:|---|---:|---:|---:|---:|---:|
| C | 60000 | coordinator | 2 | 2 | 0 | 20 | +8.3 |
| C | 60000 | fixed | 2 | 1 | 0 | 21 | +4.2 |
| core | 24000 | coordinator | 20 | 6 | 23 | 51 | -17.0 |
| core | 24000 | fixed | 14 | 0 | 29 | 57 | -29.0 |
| core | 48000 | coordinator | 56 | 12 | 13 | 19 | -1.0 |
| core | 48000 | fixed | 54 | 7 | 15 | 24 | -8.0 |

Победа команды — team_only; поражение — single_only. Разница долей равна (победы − поражения) / число пар. Для core по 100 пар в строке, для C по 24; строки нельзя суммировать как независимые наблюдения.

В summary.csv указаны медианы разностей токенов и времени в тех же парах (команда минус single), число доступных пар и отдельная оценка расхода среди пар с двумя успехами. Неизвестный usage не заменён нулём. Время прерванного эпизода неизвестно и исключено только из временной метрики, не из сравнения успехов.

Полные 448 пар — pairs.csv; разбор по темам — by_theme.csv. Совпадение хешей кода означает одинаковый текст. Разные хеши не доказывают разные результаты программы.

Это описательные результаты: два повтора одной задачи не являются двумя независимыми задачами. Статистическая значимость не заявляется. Для C показан успех по открытым проверкам; M не включён, поскольку его итоговая правильность требует проверки преподавателя.

Воспроизведение из корня mas_lr4: `python scripts/paired_analysis.py`.
