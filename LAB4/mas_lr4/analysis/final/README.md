# Полные итоговые таблицы и аудит

- summary.csv / summary.json: 15 условий — шесть T, три C, три M01–M03,
  три M04. Медианы токенов относятся только к эпизодам с полным usage.
  Время берётся только из известных длительностей; модельные вызовы —
  из эпизодов, где это поле известно. Прерванный T17 исключён только
  из этих числовых метрик, но остаётся в знаменателе успеха.
- workflow_successes: завершение с успехом по открытым проверкам,
  для M01–M03 это finished/visible_success. Не является закрытой оценкой.
  closed_correctness=not_checked для всех блоков. M04 schema_valid
  и открытые примеры показываются отдельно; неисполненный пример не равен
  успешно пройденному или установленно проваленному расчёту.
- statuses.csv: все статусы и их частоты, включая инфраструктурные ошибки.
- tokens_by_role.csv: фактический учтённый расход и вызовы каждой роли.
  При episode_usage_complete=false полный расход эпизода неизвестен.
- process_overhead.csv: доля входных токенов среди эпизодов с полным usage,
  число случаев с прошедшим тесты кодом без успешного завершения, остановки
  fixed до ревью, передачи по лимиту действий исполнителя у координатора
  и ответы finish, отклонённые за бюджетом. Это наблюдаемые признаки процесса,
  а не отдельные причинные оценки влияния каждого механизма.
- open_answer_pairs.csv / open_answer_agreement.csv: сравнение фактических
  наблюдений в открытых тестах для single и команд на тех же task/budget/repeat.
  Пара сравнима только при наличии actual для всех открытых случаев у обеих
  схем. Сравнение включает исключения/ошибки как наблюдения; одинаковый
  результат не обязательно означает правильный результат.
- validation.json: полнота 696/696, совпадение всех трёх freeze,
  идентичности эпизодов, usage из трасс/результатов/ролей и хеши артефактов.
- offline_tests.log: реальный запуск 63 offline-проверок; это не LLM-результаты.

В T два API transport error и одно пользовательское прерывание, в C 15
TimeoutError. Все они остаются неуспехами; полный usage неизвестен в 18
эпизодах и не заменяется нулём. Фактически известный расход сверх лимита
не обрезается до бюджета. Цены не заданы, денежная стоимость неизвестна.

Парная таблица четырёх исходов и разбор по темам находятся в ../paired/.
Три содержательные трассы с физическими номерами строк JSONL —
../TRACE_ANALYSIS.md. M не включён в бинарное парное сравнение по success,
поскольку финальная правильность требует контроля преподавателя.

Воспроизведение без LLM: `python scripts/final_analysis.py`.
